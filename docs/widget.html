How to install

  1. Find your store — Search above and click your location to pre-configure the snippet.
  2. Copy the snippet — Tap Copy Snippet above.
  3. Run it in Scriptable — Open Scriptable, tap +, paste the snippet, then tap ▶ to run it. The full widget script downloads and saves automatically.
  4. Add the widget to your home screen — Long-press your home screen → tap + → search for Scriptable → choose a Small or Medium widget → long-press the widget → Edit Widget → set Script to "Custard Today."

Widget Modes

The widget supports three layouts depending on widget size and configuration:

🍦 Today (Small)

Today's flavor with cone art, description, and rarity badge. Set widget size to Small.

📅 This Week (Medium)

Three-day outlook with cone art for each day. Set widget size to Medium.

📍 Multi-Store (Medium)

Compare today's flavor at up to 3 stores side-by-side. Select Multi-Store mode in Step 2 above — the snippet is pre-configured with your chosen stores automatically.
