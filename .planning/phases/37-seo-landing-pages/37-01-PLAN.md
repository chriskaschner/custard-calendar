<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL path -> handler | User-supplied path segments (state, city, slug) are untrusted input |
| Upstream flavor data -> HTML | Flavor names and descriptions from upstream could contain injection payloads |
| JSON-LD -> search engines | Malformed JSON-LD could cause indexing failures |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-01 | Spoofing | URL path parsing | mitigate | Validate slug against LAUNCH_SLUGS Set; validate city matches store's actual city via slugifyCity comparison |
| T-37-02 | Tampering | HTML output | mitigate | escapeHtml() on all dynamic content inserted into HTML (flavor names, descriptions, store names, addresses) |
| T-37-03 | Information Disclosure | Error pages | mitigate | 502 error page shows generic message, never stack traces or internal paths |
| T-37-04 | Denial of Service | Flavor fetch | accept | Existing rate limiting in index.js protects this route; KV cache prevents upstream hammering |
</threat_model>
