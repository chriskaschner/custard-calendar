function slugifyCity(city) {

}

**handleSitemap(corsHeaders, storeIndex):**
- Accept optional `storeIndex` parameter (defaults to `DEFAULT_STORE_INDEX`) for test isolation
- Build XML sitemap with `<?xml version="1.0" encoding="UTF-8"?>` declaration

- For each slug in LAUNCH_SLUGS, look up the store entry in storeIndex to get city and state
- Build URL: `https://custard.chriskaschner.com/store/${state.toLowerCase()}/${slugifyCity(city)}/${slug}/`
- Set `<lastmod>` to today's date (ISO YYYY-MM-DD format: `new Date().toISOString().slice(0, 10)`)
- Set `<changefreq>daily</changefreq>` and `<priority>0.8</priority>`
- Return `new Response(xml, { status: 200, headers: { ...corsHeaders, 'Content-Type': 'application/xml; charset=utf-8', 'Cache-Control': 'public, max-age=86400' } })`
