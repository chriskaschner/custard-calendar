<objective>
Wire og:image and twitter card meta tags into the store page HTML so social platforms fetch the PNG card when users share store page URLs. Then checkpoint for user design review.

Purpose: This is what makes the og:image discoverable -- without the meta tags in the HTML, platforms have no way to know the PNG card exists.
Output: Updated store page HTML with og:image/twitter:card meta tags, updated tests, and user-approved card design.
</objective>
