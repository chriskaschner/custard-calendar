# Requirements: Custard Calendar v4.0 Find Real Users

**Defined:** 2026-04-05
**Core Value:** A family can instantly see what flavors are at their nearby stores and decide where to go

## v4.0 Requirements

Requirements for the Find Real Users milestone. Each maps to roadmap phases.

### Data Quality

- [ ] **DATA-01**: Flavor data for 15 Madison-area Culver's stores is audited and verified clean (no closure sentinels, garbled text, missing flavors)
- [ ] **DATA-02**: Computed stats (rarity labels, gap days, "last seen", overdue calculations) are verified against raw D1 snapshots for accuracy
- [ ] **DATA-03**: Automated quality gate rejects known bad patterns before data reaches public pages and alerts on anomalies
- [ ] **DATA-04**: Historical bad records purged from D1 (closure sentinels, corrupted entries)

### SEO Pages

- [x] **SEO-01**: Worker serves HTML landing pages at /store/wi/{city}/{slug}/ with today's flavor, week-ahead schedule, store info, and rarity context
- [x] **SEO-02**: Each store page includes FastFoodRestaurant JSON-LD structured data with address, coordinates, and menu item
- [ ] **SEO-03**: Dynamic sitemap.xml and robots.txt generated by Worker for Google Search Console submission
- [ ] **SEO-04**: Per-store OG card renders a shareable preview image with flavor, store name, and cone art (design TBD with user)

### Security (SHIPPED)

- [x] **SEC-01**: Global per-IP rate limit (300/hour) on all endpoints
- [x] **SEC-02**: In-memory rate limiter (no KV quota burn)
- [x] **SEC-03**: /health gated behind admin auth
- [x] **SEC-04**: Slug validation on D1-querying routes
- [x] **SEC-05**: Daily upstream proxy cap (500/day)

### AI-Native (SHIPPED)

- [x] **AI-01**: MCP server exposes 6 tools for flavor data queries with client-side rate limiting

### Social Research

- [ ] **SOCL-01**: Instagram API access, content format, and automated posting feasibility researched with documented findings and recommendation

## Future Requirements

Deferred beyond v4.0.

### Scale SEO

- **SEO-F01**: Expand per-store pages to all 1,004 Culver's stores (after proving indexing with 15)
- **SEO-F02**: State and city index pages (/store/wi/, /store/wi/madison/)

### Social Execution

- **SOCL-F01**: Automated rarity/novelty posts to Instagram (after research validates feasibility)

### Sharing

- **SHARE-F01**: Quiz result sharing with OG cards (former Phase 34)
- **SHARE-F02**: Per-flavor share buttons on Today page

## Out of Scope

| Feature | Reason |
|---------|--------|
| Non-Culver's SEO pages | Kopp's/Gille's/Hefner's have different audiences; Culver's-only for now |
| All 1,012 stores at launch | Must prove Google indexes 15 stores before scaling |
| Page consolidation (former Phase 32) | Needs real traffic data that doesn't exist yet |
| Share buttons (former Phase 34) | No users to share from; distribution comes first |
| ML prediction improvements | Confirmed data IS the product (closed in v3.0) |
| New quiz modes | 7 modes sufficient; distribution over features |
| Mobile native app | Web-first; PWA works well |
